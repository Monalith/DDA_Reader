## r/Trackdays, r/motorcycles (English)
**Title:** I built a free, browser-based lap data analysis tool for motorcycles (Ducati DDA, RaceChrono, onboard video) — Serres example laps included

Hi all — track-day rider from Türkiye here. I got tired of the Ducati DDA Windows software so I built DDA Lab: open your .dda / RaceChrono files in the browser, satellite map with turns and apexes, lap compare with Δ time / Δ speed, math channels, markers, onboard-video sync. Files never leave your browser.
Try it with the built-in Serres laps (BMW 1000, R6 600, intermediate 1:29): https://motoracelaps.com/lab/?example=bike1000
Turn-by-turn Serres guide from the data: https://motoracelaps.com/serres-racing-circuit/
Open source (MIT): https://github.com/Monalith/DDA_Reader — feedback very welcome.
