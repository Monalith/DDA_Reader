# DDA Lab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `dda_lab/`, a MoTeC-i2-class telemetry workspace (analysis left, map right) for Ducati DDA sessions, plus a local Python bridge that lets Claude Code interpret imported track schemas.

**Architecture:** Pure-logic TypeScript modules (`src/core/*`: parser, resampling, processing, track model, reports, math expressions, affine fit) with no DOM dependency and full Vitest coverage; a Zustand store (`src/state/*`) holding sessions/workspace; React components (`src/ui/*`) for layout, uPlot chart stack, MapLibre map, panels. FastAPI bridge `dda_lab_bridge.py` shells out to `claude -p`.

**Tech Stack:** Vite 6, React 18, TypeScript 5 (strict), Zustand 5, uPlot 1.6, maplibre-gl 4, zod 3, papaparse 5, Vitest 3, Playwright 1.5x, Python 3.11 FastAPI + uvicorn (in `../dda_venv`).

**Spec:** `docs/superpowers/specs/2026-10-04-dda-lab-design.md`

## Global Constraints

- All code under `DDA_Reader/dda_lab/` (web) and `DDA_Reader/dda_lab_bridge.py` + `DDA_Reader/tests/test_bridge.py` (Python). Never modify `viewer/` (classic viewer).
- No API keys; map tiles: Esri World Imagery `https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer/tile/{z}/{y}/{x}` and OSM `https://tile.openstreetmap.org/{z}/{x}/{y}.png`.
- Common time base 10 Hz; `Float32Array` for channel data, `Float64Array` for time; `NaN` = missing.
- Units internal: km/h, m, s, deg, g. Display conversion only in UI.
- `npm test` (Vitest) must stay green after every task; `npm run typecheck` (tsc --noEmit) must pass.
- Node 24 is installed; use `npm` (no pnpm).
- Commit after each task with conventional-commit messages; do not push.
- Python tests run with `../dda_venv/bin/python -m pytest tests -q` from `DDA_Reader/`.

### Task 1 (G1): .dda parser port

**Files:** Create `src/core/ddaParser.ts`, `tests/unit/ddaParser.test.ts`, `tests/fixtures/sample_expected.json` (generated once by Python).

**Produces:**
```ts
export interface DdaChannelDesc { name: string; unit: string; desc: string; sizeBytes: number; periodCs: number }
export interface ParsedDda { meta: { track: string; rider: string; note: string; odo: number }; channels: DdaChannelDesc[]; series: Record<string, { t: Float64Array; v: Float64Array }>; durationS: number }
export const CHANNEL_SPECS: Record<string, [sizeBytes: number, periodCs: number]>; // same table as dda_merge.py
export function parseDda(buf: ArrayBuffer): ParsedDda;
```
Algorithm = `dda_merge.py`/whitepaper: header v4; names at 0x2a (64) / 0x6a (64); count at 0x1ad; descriptors 80 B from 0x1ae (name 16 B, desc+unit NUL-terminated from +0x16); data at 430+80·n; then per 1/100 s slot, for each channel in table order whose `t % periodCs === 0`, read little-endian unsigned (int32 signed for GPS_LON/LAT, int16 signed for GPS_ALT). Scales: speed ×0.065625 km/h, tps ×0.5 %, lean = raw×0.054931640625 − 450, lon/lat ×1e-6, alt ×0.1 m, lap bytes 0xFF = none else hundredths. Stop when fewer bytes remain than the next field.
