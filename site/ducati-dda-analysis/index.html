Ducati DDA data analysis in your browser

The Ducati Data Analyser (DDA, DDA+ with GPS) records speed, rpm, throttle, gear, lean angle, torque reduction (DTC) and GPS at up to 100 Hz into .dda files. DDA Lab opens those files directly — no Windows software, no installation — and turns them into a professional lap analysis workspace.

Open your .dda files

What is in a .dda file

ChannelRateNotes
Speed10 Hzwheel speed, km/h
RPM50 Hzengine speed
Throttle (GAS)20 Hz% opening
Gear10 Hz0–6
Lean angle20 Hzdegrees, left negative
Torque reduction (DTC fast / slow)20 Hztraction-control intervention
GPS lat / lon / altitude10 HzDDA+ GPS versions
Lap / intermediate markers1 Hzbeacon or GPS laps

DDA Lab decodes the format in the browser (the file format was reverse-engineered and documented in the open-source DDA_Reader project). Your file is never uploaded.

What you can do with it

  • Merge a whole day of Run0xx.dda files into one session and see every lap in one table with sector times and best-lap highlighting.
  • Satellite map of the track vectorised from your own GPS, with turns, apexes, braking and throttle points; colour the trace by speed, lean, throttle or braking.
  • Lap comparison: pick a reference lap and read Δ time, Δ speed, Δ lean and Δ throttle corner by corner (stock-chart style, green = gained, red = lost).
  • Math channels: ~60 functions, filters, integrals, formulas per lap or per run, ref() / run() to subtract one run from another.
  • Markers & notes, per-panel zoom, templates, reports, CSV and bundle export, onboard-video sync.
  • Virtual rider: a parametric lap-time simulator on your track to test "what if I braked 0.1 g harder".

Supported bikes and files

Any Ducati with the DDA or DDA+ GPS kit (Panigale V2/V4, 1199/1299, 899/959, Streetfighter, Monster, Multistrada, Hypermotard…). Also opens DDA_Reader .json/.csv exports, RaceChrono and onboard-video telemetry JSON, and DDA Lab .lab.json bundles.
